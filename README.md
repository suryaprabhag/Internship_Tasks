## How to Run Python Programs

1. Install Python 3.
2. Clone or download this repository.
3. Open the project in Visual Studio Code.
4. Navigate to the required task folder.
5. Execute the Python program.

Example for Task 3:

```bash
cd Python_Tasks/Task_3
python main.py
```

To run Jupyter Notebooks, open the `.ipynb` file in VS Code or Jupyter Notebook and execute the cells.
