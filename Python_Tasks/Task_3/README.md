# Task 3 - Python Problem Solving

This task contains 15 Python programming problems focused on logical thinking, data structures, and problem-solving techniques.

## Files

- **solutions.py** – Contains 15 separate functions, one for each question.
- **main.py** – Imports all functions, runs test cases, and prints the results.
- **problem_solving.ipynb** – Contains pseudocode, Python implementations, example inputs, and execution outputs.

## Topics Covered

- String and character frequency
- Dictionaries and sets
- Anagram checking
- List manipulation
- Duplicate removal
- Finding missing numbers
- Pair sum problems
- List rotation
- Consecutive element calculations

## Execution

Run the following command from the Task_3 folder:

```bash
python main.py
```

Each function returns its result, and `main.py` displays the outputs for the given examples and additional test cases.
